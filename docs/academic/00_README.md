# Academic Research Docs — Digital & Mobile Forensics Lab

> Bộ tài liệu định vị **repository này** như nền tảng **phân tích / nghiên cứu học thuật** về digital forensics và mobile forensics, phục vụ:
>
> 1. Đánh giá năng lực kỹ thuật & độ phủ artifact  
> 2. Tài liệu học thuật / giáo trình / paper  
> 3. Định hướng phát triển **hai ứng dụng trích xuất & phục hồi dữ liệu** (Disk + Mobile)

**Không phải** mã nguồn sản phẩm thương mại. Repo cung cấp know-how, case study, dataset công khai, mô hình evidence (xSTIX/CFO), và lab AI — để đội sản phẩm **đánh giá, thiết kế, kiểm thử**.
